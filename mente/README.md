# mente/

Este es el segundo cerebro del señor dentro de VSCode: un lugar para volcar
ideas, decisiones y contexto de negocio y de vida, en markdown plano,
versionado junto al código.

## Mapa

```
mente/
├── README.md                      ← estás aquí
├── profesional/
│   ├── proyectos.md                ← qué está activo, qué está en pausa
│   └── unity-street/
│       ├── marca.md                ← identidad, tono, valores
│       ├── catalogo.md             ← productos, categorías, pendientes
│       └── estrategia.md           ← precios, canales, metas de negocio
├── personal/
│   └── notas.md                    ← vida personal, separada de lo laboral
├── decisiones/
│   └── registro.md                 ← bitácora de decisiones importantes
└── tareas/
    └── inbox.md                    ← todo lo que aún no tiene carpeta
```

## Reglas de uso

- **Separación estricta personal / profesional.** Si una nota mezcla
  ambas cosas, se parte en dos. `personal/` no debe contener nada de
  UNITY STREET ni de otros proyectos de trabajo, y viceversa.
- **`tareas/inbox.md` es la puerta de entrada.** Cuando no sepas dónde
  poner algo, va ahí primero. Se revisa y se mueve a su carpeta correcta,
  no se queda acumulando.
- **`decisiones/registro.md` es de solo-agregar.** No se edita el pasado;
  si una decisión cambia, se registra la nueva entrada y se referencia la
  anterior.
- Todo en español, salvo términos técnicos que no tengan traducción útil.
